# ParkTrack Local — готовая сборка для Windows

Эта сборка запускает локально весь минимально необходимый контур ParkTrack:

- PostgreSQL и миграции базы данных;
- FastAPI-сервер;
- административную панель;
- модель распознавания автомобилей OpenVINO;
- MinIO для снимков модели;
- демонстрационную камеру, зону и тестовое MP4-видео.

Python, Node.js и PostgreSQL отдельно устанавливать не нужно — они находятся внутри Docker-контейнеров.

## Что установить

1. Docker Desktop для Windows.
2. Git — только если вы будете работать с исходными репозиториями. Для запуска этого ZIP Git не требуется.

В Docker Desktop должен использоваться режим Linux containers и WSL 2. После установки перезагрузите компьютер и дождитесь статуса **Docker Desktop is running**.

## Первый запуск

1. Распакуйте ZIP, желательно в короткий путь без кириллицы, например `C:\ParkTrack-local`.
2. Запустите `start-parktrack.bat`.
3. Разрешите Docker скачать образы. Первый запуск обычно занимает 10–30 минут и несколько гигабайт места.
4. После запуска откроются административная панель и документация API.

Адреса:

- панель: <http://127.0.0.1:5173>;
- API и проверка запросов: <http://127.0.0.1:8000/docs>;
- проверка API: <http://127.0.0.1:8000/api/v1/health>;
- MinIO: <http://127.0.0.1:9001>.

Учётная запись панели:

```text
Логин:  admin@parktrack-demo.com
Пароль: ParkTrack123!
```

Учётные данные предназначены только для локальной учебной сборки.

## Что должно произойти автоматически

При первом запуске система:

1. создаст базу данных и таблицы;
2. создаст локального администратора;
3. добавит камеру «Демо-парковка»;
4. подключит `test-media/demo-parking.mp4`;
5. создаст зону в верхней части кадра, где находятся автомобили;
6. запустит модель и начнёт сохранять результаты.

Один цикл модели получает кадры около отметок 0, 10 и 20 секунд, выполняет распознавание, обновляет занятость зоны и сохраняет исходный и размеченный снимки.

## Как посмотреть работу модели

Откройте `logs-parktrack.bat`. В журнале `detector` должны появляться строки о выбранной камере, пороге confidence и итоговый JSON.

В панели откройте разделы «Камеры», «Зоны» или «Аналитика». Первое распознавание на CPU может выполняться несколько минут.

Пустая Яндекс.Карта не мешает распознаванию. Для карты нужен отдельный API-ключ, которого в учебной сборке нет.

## Как подключить своё видео

Самый простой вариант:

1. остановите проект через `stop-parktrack.bat`;
2. замените `test-media/demo-parking.mp4` своим файлом;
3. имя должно остаться `demo-parking.mp4`;
4. снова запустите `start-parktrack.bat`.

Поддерживаются и прямые источники в поле `source` камеры:

- `rtsp://...`;
- прямая ссылка на `.m3u8`;
- прямая HTTP/HTTPS-ссылка на MP4;
- URL изображения с камеры.

Источник можно изменить в разделе «Камеры» административной панели. Если поток запущен на вашем компьютере, вместо `localhost` в адресе для Docker используйте `host.docker.internal`. Например:

```text
rtsp://host.docker.internal:8554/camera
```

Не используйте ссылку на обычную веб-страницу или страницу YouTube — модели нужен прямой медиапоток. Используйте только собственные или разрешённые публичные камеры.

После замены источника запустите `restart-detector.bat`.

## Служебные файлы

| Файл | Назначение |
|---|---|
| `start-parktrack.bat` | собрать и запустить весь проект |
| `stop-parktrack.bat` | остановить проект, сохранив данные |
| `status-parktrack.bat` | показать состояние контейнеров |
| `logs-parktrack.bat` | показать журналы API и модели |
| `restart-detector.bat` | перезапустить модель после изменения источника |
| `reset-all-data.bat` | удалить базу и снимки, затем начать с чистого состояния |

## Если проект не запускается

1. Убедитесь, что Docker Desktop полностью запущен.
2. Проверьте, что свободны порты `5173`, `8000`, `9000`, `9001` и `5252`.
3. Запустите `status-parktrack.bat`.
4. Запустите `logs-parktrack.bat` и сохраните последние строки ошибки.
5. Если база осталась после неудачного первого запуска, используйте `reset-all-data.bat`, затем повторите запуск.

Для остановки просмотра логов нажмите `Ctrl+C` — сами контейнеры продолжат работать.

## Что изменено относительно исходных репозиториев

- устаревшая ссылка Compose на отсутствующий `labeler` заменена актуальной `admin-panel`;
- добавлены PostgreSQL, миграции, MinIO и автоматическое создание начальных данных;
- локальный MP4 смонтирован одновременно в API и детектор;
- исправлено получение трёх кадров из видеофайла: используются временные позиции файла, а не ожидание по настенным часам;
- добавлен безопасный вариант работы камеры без реальной калибровки;
- добавлены команды запуска для Windows.

Исходные части проекта взяты из публичной организации ParkTrack-Project на GitHub. Лицензии и файлы исходных репозиториев сохранены внутри соответствующих папок.
