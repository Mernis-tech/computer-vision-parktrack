# Устранение ошибок

## Камера показывает последний кадр, но распознавания нет

- проверить, что камера активна;
- создать и активировать зону;
- проверить прямой URL потока;
- открыть журнал контейнера `detector`;
- убедиться, что API и MinIO доступны;
- дождаться полного интервала следующего цикла.

## Проект не запускается

- проверить, что Docker Desktop работает;
- проверить свободные порты `5173`, `8000`, `9000`, `9001` и `5252`;
- выполнить `docker compose ps`;
- посмотреть `docker compose logs --tail=200 api detector`;
- проверить заполнение `.env`.

## Заканчивается место на диске

Основной объём занимают снимки MinIO. Перед удалением данных сделайте резервную копию нужных кадров и базы. Затем уменьшите частоту обработки или настройте срок хранения.
