# Разработка

## Перед изменением

- создать Issue;
- создать ветку от `develop`;
- не добавлять секреты и снимки камер;
- описать способ проверки результата.

## Минимальная проверка

1. Docker Compose успешно собирается.
2. API health-check возвращает успешный статус.
3. Админ-панель открывается.
4. Камера и зона создаются.
5. Детектор создаёт новое наблюдение.
6. Исходный и размеченный снимки доступны из истории.

Изменение модели дополнительно проверяется на общем размеченном наборе данных.
