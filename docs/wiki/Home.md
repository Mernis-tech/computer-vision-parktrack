# Wiki проекта

Wiki должна отвечать на три вопроса: как запустить проект, как им пользоваться и как его разрабатывать.

## Разделы

1. [Быстрый старт](Quick-Start.md)
2. [Архитектура](Architecture.md)
3. [Работа с камерой](Camera-and-Zone.md)
4. [Разработка](Development.md)
5. [Сервер и эксплуатация](Deployment.md)
6. [Устранение ошибок](Troubleshooting.md)

## Страницы, которые стоит добавить позже

- API и примеры запросов;
- форматы камеры и зоны;
- сравнение моделей и методика теста;
- резервное копирование и восстановление;
- безопасность и управление секретами;
- FAQ;
- журнал архитектурных решений;
- история релизов.

Исходники Wiki хранятся в `docs/wiki`, чтобы изменения проходили обычный Pull Request. После создания GitHub Wiki эти страницы можно перенести туда без изменения структуры.
