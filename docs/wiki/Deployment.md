# Сервер и эксплуатация

Для комфортного учебного запуска рекомендуется 4 vCPU, 8 ГБ RAM и 50 ГБ SSD. Видеокарта не обязательна, поскольку текущий детектор использует CPU.

Перед открытием сервиса в интернете нужно:

- заменить все демонстрационные секреты;
- установить reverse proxy и HTTPS;
- не публиковать порты PostgreSQL и MinIO;
- настроить резервное копирование;
- ограничить срок хранения снимков;
- включить ротацию журналов и мониторинг свободного диска.

Подробный расчёт находится в `docs/SERVER_REQUIREMENTS.md`.
