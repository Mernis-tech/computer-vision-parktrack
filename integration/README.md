# Интеграционный модуль

В этой папке будет находиться сервис, который запускает нашу модель и работает по контрактам ParkTrack.

Планируемые обязанности сервиса:

1. получить активную камеру через API ParkTrack;
2. получить кадры из RTSP, HLS, MP4 или HTTP-источника;
3. запустить нашу модель `best.pt`;
4. сопоставить найденные автомобили с многоугольными зонами;
5. отправить занятость зон и историю наблюдений в API;
6. сохранить исходный и размеченный кадры в хранилище снимков.

На первом этапе сервис будет использовать Ultralytics напрямую. После проверки качества модель можно экспортировать в OpenVINO и подключить к существующему детекторному контуру ParkTrack.
